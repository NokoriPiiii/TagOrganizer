# Tag Organizer (Java)

A simple Java application to organize items by tags.  
Useful for managing datasets, documents, or prompts for LLM workflows.

## ✨ Features
- Add/remove tags for items
- Search items by tag
- Display all items with their tags
- Case-insensitive tag handling

## 🚀 Getting Started
### Prerequisites
- Java 8+  
- Git (optional, for version control)

### Run
```bash
javac src/TagOrganizer.java
java src.TagOrganizer
